# Upstream triage

Triage of the issues and pull requests in [xpgo/obsidian-folder-note-plugin](https://github.com/xpgo/obsidian-folder-note-plugin), done on 2026-11-10 against this fork at `feb3bf4`.
It is based on reading the code, not on live testing. Rows marked `unknown` need a live repro (use `npm run test:e2e` or the Obsidian CLI).
Upstream issues are cited as `xpgo#N`; do not confuse them with issues in this repo.

- **107 issues triaged** (feature: 41, bug: 28, duplicate: 15, already-fixed: 10, question: 6, stale: 4, invalid: 3); **57 marked worth importing** as tracking issues here.
- **12 PRs reviewed.** Only #119 is a worthwhile source of changes, and only in slices. See the PR section.

## Suggested work packages

Ordered by value for effort. Issue numbers are upstream numbers.

1. **Card images** (xpgo#2, #37, #43, #54, #55, #60, #66, #88, #94, #103). In `folder-brief.ts getContentImage` strip `|size` and `#heading`, accept only image files, resolve with `metadataCache.getFirstLinkpathDest(link, notePath)` and `vault.getResourcePath`, and quote the CSS `url()` (apostrophes). Related PRs: #119, #95.
2. **ccard context and filtering** (xpgo#8, #49, #74, #50). Use `ctx.sourcePath` instead of `getActiveFile()`, and build the list from `TFolder.children` (this also drops `.obsidian`). Related PR: #119.
3. **Link-safe rename, move and delete** (xpgo#13, #65, #12, #93, #100). Use `app.fileManager.renameFile` and `trashFile` instead of `vault.adapter.*`; move the note when an Outside-mode folder moves. Related PR: #119.
4. **Hidden/marked state** (xpgo#78, #98, #38, #102, #19, #106). Apply `has-folder-note`/hidden state on layout-ready, on explorer re-render and when settings change, not only after a click. Fixing the stale CSS variables (xpgo#41, #77, #85) belongs here.
5. **Click behavior** (xpgo#58, #1, #62, #80, #97, #39, #69, #18, #67, #110). Add a setting for plain-click behavior (open / modifier only / no collapse), open in a new tab on middle-click, and fix the `metaKey` handling in `main.ts` (xpgo#110).
6. **Creating folder notes** (xpgo#45, #36, #91, #47, #64, #27, #26). Add a `file-menu` entry for folders (also the only way to create notes on mobile), an Index branch in `newNoteFolder`, optional auto-create, and a name template for prefix/suffix.
7. **ccard features** (xpgo#71, #105, #14, #32, #86, #25 folder cards link to folder notes; #15, #112 sorting; #44, #96, #30, #109, #21, #63 frontmatter/tags/longer brief; #61, #90, #99 display options). Related PR: #87 (reimplement).
8. **Docs and small fixes.** README typos (xpgo#115 via PR #104), Waypoint tip for graph view (xpgo#17, #34, PR #59), answers for the question issues.

Likely to skip: xpgo#11, #16, #23, #35, #40, #56, #57, #68, #70, #76 (canvas index), #92, #107, #113 (breadcrumb DOM is fragile).
